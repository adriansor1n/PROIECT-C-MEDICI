🏥 Sistem de gestionare a unui cabinet medical

Acest proiect este o aplicație de tip consolă, dezvoltată în limbajul C, care permite gestionarea informațiilor despre medicii unui cabinet medical.

Aplicația oferă un meniu interactiv prin intermediul căruia utilizatorul poate vizualiza lista medicilor și poate căuta informații despre aceștia în funcție de nume, specialitate sau programul de lucru.
